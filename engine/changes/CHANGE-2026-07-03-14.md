# CHANGE-2026-07-03-14 — Engine v6 auto-update + migration mechanism

> Created: 2026-07-03 · Status: verified · Related plan: none · Related task: T-013 · Related decision: D-014

## Goal
引入自动检测更新机制 + 完善迭代迁移机制 + 远程拉取自动更新闭环,确保正在进行中且运用老引擎文件结构的项目能够完整更迭到 v6 的所有机制。

## Actual Changes
- **版本权威源**:新增 `VERSION`(仓库根)+ `plugin/VERSION` + `engine/VERSION`,三者一致 = 6.0。
- **`engine check-update` 子命令**(新):对比本地 `engine/VERSION` vs 远程 VERSION,exit 0=最新 / 7=有更新 / 8=网络错。双实现 `engine-check-update.{sh,ps1}`。
- **`engine migrate` 子命令**(新):单独运行契约迁移器(幂等,修复/重试用)。
- **`engine update` 增强**:一站式 拉取→migrate→doctor;加 `--check-only` / `--no-migrate` 选项。
- **`engine-migrate-contract.{sh,ps1}` 增强**:CONTRACT_VERSION 读 VERSION(6.0);v6 contract block body(任务卡机读头/决策台账/联邦表/三层门禁/契约编译/驾驶舱/N1-N5);新增 `ensure_structure`(创建 tasks/decisions/domains/changes/evidence/.cache 目录 + federation.json + rules.json + VERSION 印记)。
- **`plugin/migrations/v6.0.{sh,ps1}`**(新):版本化迁移 step,委托 migrator;智能查找 migrator 路径(plugin 树与已安装项目树皆可);未来 v6.1+ 追加 sibling。
- **session-start hook 增强**:24h 缓存 `engine/.cache/update-check.json`,温和提示更新(fail-open,联网失败/无 curl 静默跳过,绝不阻塞会话)。
- **Doctor 加 `check_engine_version`**:检测 `engine/VERSION` 存在 + 与仓库 VERSION 一致(warn/fail 分级)。
- **check.sh / check.ps1 加 VERSION stamp step**:三者一致校验。
- **install.sh / install.ps1 / manifest.json**:加 VERSION + check-update + migrations 分发条目。
- **engine-sync.md** step 3 更新:反映 `engine update` 一站式 + `engine migrate` 单独可跑。
- **AGENTS.md**:v5.5 → v6.0 + engine CLI 更新命令说明。

## Impact Scope
引擎运行时(engine-runtime 域):CLI + hooks + migrator + doctor + check + install + manifest + bootloader。
老项目迁移机制:从"只写 contract block"升级为"block + v6 数据层结构创建"——老项目跑一次 `engine migrate` 即获得完整 v6 机制骨架。

## Risk & Watchpoints
- session-start 现在联网(`curl --max-time 5`)检测更新,首次会话可能多 5 秒;fail-open 保证离线/无 curl 时静默跳过,绝不阻塞。
- `engine update` 自动跑 migrate + doctor,会修改老项目的 `engine/` 目录(创建空数据层结构 + federation.json + VERSION);幂等,可重跑,不碰用户业务代码与 `engine/*.md` 项目记忆。
- migrator **不**升级已有任务卡格式(只创建目录骨架),老任务卡保持原样;新任务卡须用 v6 机读头(由 Stop hook + pre-commit 守门)。
- `contract/src/` 未改(FORBIDDEN),`ENGINE_FILE_SYSTEM_v5.md`(dist 产物)未改(会被 compile 覆盖);版本机制说明通过 AGENTS.md + engine-sync.md + CLI help 传达。
- `engine/VERSION` 在开发仓库手动创建(狗粮);用户项目由 install/migrator 自动创建。
