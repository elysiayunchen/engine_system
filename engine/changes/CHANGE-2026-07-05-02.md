# CHANGE — 2026-07-05-02

> scope: engine-runtime | risk: low | rollback: revert commit

## 做了什么

T-016: GitHub Release 自动化 workflow。

1. 新建 `.github/workflows/release.yml`：tag push (`v*`) 触发 → 从 change capsules 增量生成 release notes → 打包 plugin/ 为 tarball + zip → 生成 SHA256 checksums → `gh release create` 上传全部产物
2. 更新 `scripts/release.sh`：结尾提示改为「push tag 后 workflow 自动发布」，手动 `gh release create` 降级为 fallback
3. 支持 pre-release 检测（版本号含 alpha/beta/rc 自动标记）
4. 增量 release notes（对比上一个 tag，只收新 capsule）

## 影响

- 发版流程从「release.sh + 手动 gh release create」变为「release.sh → push → 自动」
- T-017（完整性校验）的 checksums 文件由此 workflow 产出
- T-018（离线包）的 tarball 可在此 workflow 中追加

## 风险

- 低：workflow 只在 tag push 时运行，不影响日常开发
- GITHUB_TOKEN 权限 `contents: write` 是 GitHub Release 创建的最小权限
