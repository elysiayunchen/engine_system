# CHANGE — 2026-07-05-03

> scope: engine-runtime | risk: low | rollback: revert commit

## 做了什么

T-017: 版本锁定安装 + 完整性校验。

1. install.sh 加 `--version TAG` 参数：指定版本时优先从 GitHub Release artifact 下载，不可用时 fallback 到 raw content URL；无参数时行为不变
2. install.sh 加 `--help` 参数和 SHA256 完整性校验（`verify_checksums` 函数，best-effort fail-open）
3. install.ps1 加 `-Version` 参数：同样的 release-first + fallback + SHA256 校验逻辑
4. manifest.json 加 `sha256` 字段（当前 placeholder，release workflow 产出真实值后自动生效）

## 影响

- 用户现在可以 `bash install.sh --version 6.0.1` 安装特定版本
- Windows 用户可以 `install.ps1 -Version 6.0.1`
- 默认行为完全不变（无参数仍从 main 拉取）
- SHA256 校验基础设施就绪，首次 release 含真值后自动启用

## 风险

- 低：新增功能不影响现有默认路径
- manifest.json 加了一个字段，不影响现有解析
