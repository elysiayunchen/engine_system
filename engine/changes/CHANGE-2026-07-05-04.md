# CHANGE-2026-07-05-04 — T-018 离线安装包

## Goal
离线安装包——release workflow 产出 `engine-system-vX.Y.Z-offline.tar.gz`（含 plugin/ 完整树 + install 脚本），install.sh 支持 `--local PATH` 模式从本地 tarball 安装（不联网），install.ps1 支持 `-Local` 等价参数。

## Actual Changes
- `.github/workflows/release.yml`: 新增 offline tarball 打包步骤——将 `plugin/*` + `install.sh` + `install.ps1` 合入临时目录，产出 `engine-system-vX.Y.Z-offline.tar.gz`，并纳入 checksums + gh release create
- `install.sh`: 新增 `--local PATH` 参数解析（tarball 自动解压 / 目录直接使用）；下载循环加 `LOCAL_DIR` 分支用 `cp` 替代 `download`/`download_versioned`；runtime-law.md 加本地拷贝分支；checksum 验证在 `--local` 模式下跳过
- `install.ps1`: 新增 `-Local` 参数 + `Copy-Local` helper（`/`→`\` 路径映射）；下载循环、runtime-law.md、checksum 验证均加 `$LocalDir` 分支，与 install.sh 对等

## Impact Scope
- `.github/workflows/release.yml`（CI/CD 产出新增 offline artifact）
- `install.sh`、`install.ps1`（安装器新增离线模式，不影响现有在线安装流程）
- 离线安装结果与在线安装一致（同文件集、同目录结构）

## Risk & Watchpoints
- offline tarball 不含 `runtime-law.md`（在 `contract/` 编译产物目录，不在 `plugin/` 内）→ release.yml 需额外从 repo 根拷贝，或 `--local` 模式降级为 skip（当前实现：`$LOCAL_DIR/runtime-law.md` 存在则拷贝，不存在则跳过）
- tarball 大小约束 <5MB（plugin/ 纯 markdown + shell 脚本，当前远小于阈值）
- Windows `tar` 命令兼容性：Windows 10 1803+ 内置 `tar.exe`，与 PowerShell 的 `tar` 别名兼容

- release.yml 删除 offline tarball 步骤即可，其余 artifact 不受影响
