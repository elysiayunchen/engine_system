# CHANGE-2026-07-19-02 — Doctor spec twin 误判 hotfix

> Created: 2026-07-19 · Status: published · Related: none (hotfix)

## Goal

修复 Doctor 在扫描任务卡时把 `T-*.spec.md`(spec twin 文件)误判为任务卡的 bug。具体表现:

1. **FAIL**:`task T-033.spec done without complete PASS evidence (no declared AC)` —— T-033.spec.md 正文里有字面量 `status: done`(出现在 AC 描述"任务卡 status: done 时 MUST 更新涉及域 INVENTORY"),被 `grep -q 'status:.*done'` 误匹配。
2. **WARN**:`4 task card(s) missing v6 headers` —— 4 张 spec twin(T-031/032/034/035.spec.md)没有 v6 机读 header(write-set:/status:),被当 legacy 任务卡。

根因:bash glob `T-*.md` 匹配 `T-*.spec.md`(因 `*` 在 bash glob 匹配任意字符含 `.`);PowerShell `-Filter "T-*.md"` 同样匹配。spec twin 本是 AC 验收清单,不是任务卡,不该被任务卡扫描逻辑覆盖。

## Actual Changes

### Doctor 实现(sh + ps1 双胞胎 × engine + plugin 镜像 = 4 份)

- `engine/scripts/engine-doctor.sh`:
  - `check_task_card_done_evidence()` 循环加 spec twin 跳过判断(bash glob 模式匹配 `*.spec.md` 后 continue,L518)。
  - `check_engine_tasks_health()` legacy 任务卡扫描循环加同样过滤(L592)。
- `engine/scripts/engine-doctor.ps1`:
  - `Test-TaskCardDoneEvidence` 循环加 `if ($f.Name -match '\.spec\.md$') { continue }`(L602)。
  - `Test-EngineTasksHealth` legacy 任务卡扫描改用 `Where-Object { $_.Name -notmatch '\.spec\.md$' }` 过滤(L693)。
- `plugin/engine/scripts/engine-doctor.sh` + `.ps1`:镜像同步,4 处改动与 engine/ 完全一致。

### 显式未改

- **未收紧 grep 模式** `status:.*done`。收紧仍是治标——任何正文字面引用都可能再触发。glob 排除 spec twin 是语义正确做法:spec twin 本来就不是任务卡。
- **未改 `T-*.md` glob 模式本身**。glob 本身没错,错的是没排除 spec twin。
- **未补 ENGINE_DOCTOR.md 检查项**。这是 bug 修复,不是新增检查。

## Impact Scope
