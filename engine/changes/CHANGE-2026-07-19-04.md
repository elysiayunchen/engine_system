## Impact Scope

- **新机制**:任务级压缩恢复锚点,机器强制注入,不靠 agent 自觉
- **不替代**:HANDOFF.md 会话级恢复(只在其存在 active 卡时退化为薄指针)
- **不引入**:PreCompact hook(机制错配已证:Claude Code 沙箱不允许 hook 触发 agent 磁盘写入)
- **不破坏**:v6.6 既有门禁与 HANDOFF 归档机制(D-027)
- **迁移宽限期**:contract-version < 6.7.0 的项目 WARN,>= 6.7.0 FAIL(与 D-028 §9 一致)

## Risk & Watchpoints

- **Session injection budget**:progress.md 注入使 SessionStart 输出从 269 → 384 行(接近 400 上限)。若 active 卡 > 1 个且每个 progress.md 接近 4KB,可能超限。缓解:progress.md ≤4KB 硬限 + 事件驱动更新(非每步)防止膨胀
- **多 active 卡场景**:若同时有 3+ active 卡,SessionStart 注入会显著增加 token 占用。缓解:实际项目中通常 ≤2 active 卡,且 progress.md 设计为精简锚点而非完整笔记
- **迁移宽限期误判**:旧项目 ENGINE_DOCTOR.md 无 contract-version 标记时 cv_int=0 → WARN(不 FAIL),与 D-028 §9 grace period 一致
