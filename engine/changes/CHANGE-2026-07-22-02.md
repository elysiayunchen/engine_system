## Risk & Watchpoints
- **豁免阈值是经验值**:estimated_steps ≤ 10 是基于 T-039(8 步)和 T-037(2 步)的实证,不保证对其他类型小任务都合适。后续若发现 11-15 步任务也想豁免,考虑提升阈值或加 AC 数量阈值。
- **checkpoint_plan=inline 是必需条件**:tryout 卡不豁免(tryout 是试错卡,可能仍然复杂,如 T-036 estimated_steps=18)。架构师显式声明的其他 inline 等价 bypass 值也接受。
- **Doctor 不强制豁免**:本豁免由 agent 自觉遵守契约文本。Doctor 仍按 FILE 13 既有逻辑检查 progress.md 存在性 + 迁移宽限期,不检查 §2-§7 是否 n/a 占位。后续若发现 agent 滥用豁免(把大任务也写成 n/a),考虑加 Doctor 检查。
- **本任务自身狗粮**:T-040 progress.md 仅填 §1 + §4,§2/§3/§5/§6/§7 写 n/a 占位。验证豁免条款实际可用。
