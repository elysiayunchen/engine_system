# CHANGE-2026-07-23-03 — T-044 P037 legacy fallback removal

> task: T-044 | version: v6.11.6 | decision: D-032 (approved) | issue: #10 (P037) | related: T-043 (P038, v6.11.5)

## Goal

Fix GitHub issue #10 P037 — pre-commit legacy fallback (formerly L89-94, became L111-116 after T-043 parser rewrite shifted line numbers) picked the lex-largest done task card as the governing card when no active card existed + strict_task_mode=0 (contract-version < 6.5). This caused historical done cards to govern new unrelated commits, falsely blocking or mis-routing them. Done cards are cold history and must not govern new commits.

## Impact Scope

- **Affected projects**: contract-version < 6.5 (strict_task_mode=0) with no active/closing task card. These projects previously had done-card fallback govern their commits; now fail-open (skip task-card governance, protected_paths still checked).
- **Behavior change**: Old projects (<6.5) without an active card will now block protected-path commits (previously the fallback done card's decision could cover them). Mitigation: upgrade to 6.5+ for strict mode, or create an active card.
- **Unaffected**: v6.5+ projects (strict_task_mode=1) — unchanged (still require active card). Active-card scenarios — unchanged (governs normally).

## Risk & Watchpoints

- **Lost fallback safety net**: Old projects (<6.5) without active card now have zero task-card validation (pure fail-open for task-card governance). protected_paths/worker mode/memory-written checks still apply.
- **Behavior break for old projects relying on fallback**: Rare, but if any user depended on done-card fallback governing their commits, they lose it. CHANGELOG explicitly flags the behavior change.
- **C6/C7 test semantics shifted**: The task-card gate tests now encode the new behavior (done card → block). Any documentation referencing "done-card fallback" should be updated.

## Rollback

Revert commit (git revert). The removed block was:
```bash
if [ -z "$task_file" ] && [ "$strict_task_mode" -eq 0 ]; then
  for f in $(ls -1 "$ENGINE_DIR"/tasks/T-*.md 2>/dev/null | sort -r); do
    [ -f "$f" ] || continue
    if grep -q 'status:.*done' "$f" 2>/dev/null; then task_file="$f"; break; fi
  done
fi
```
Re-adding this block restores legacy fallback. Also revert C6/C7 expected rc in run-task-tests.sh.
