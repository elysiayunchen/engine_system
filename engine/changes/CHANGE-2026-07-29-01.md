## Risk & Watchpoints

- **匹配引擎是 shell case glob 子集,非完整 gitignore 语义**:不支持 `!` 取反、`/anchor` 锚定、`**/` 跨层。issue 提案的 `git check-ignore --exclude-from` 不可行(该选项不存在)。已在 D-036 记录。
- **逗号注入**:`.engineignore` 含字面逗号的 pattern 会被 tr 拆成两个。低风险,gitignore pattern 极少用逗号。
- **memory write-back gate 未旁路**:提交 engineignored 文件仍触发 "code changed but no memory staged"——有意行为(锚点同步也算代码变更)。
