## Goal

修复 engine-verify.ps1 L54-64 Git Bash 检测仅查 `C:\Program Files\Git\bin\bash.exe` + Get-Command bash(排除 WSL stub),漏检 32-bit Program Files 路径、自定义安装路径、bash on PATH 是 WSL stub 但 Git Bash 存在于 git install dir 的场景。检测失败 → fallback `cmd /c` → 无 grep → AC verify 全 FAIL。

## Actual Changes

**A. engine-verify.ps1 L54-97 bash 检测链扩展(engine + plugin 镜像)**

- A-1:标准 64-bit 路径(回归):`Test-Path "C:\Program Files\Git\bin\bash.exe"`。
- A-2:32-bit 路径(新):`${env:ProgramFiles(x86)}\Git\bin\bash.exe`(env var 优先,硬编码兜底)。
- A-3:Get-Command bash(回归):排除 `*\System32\bash.exe`(WSL stub)。
- A-4:git --exec-path 反推(新):`git --exec-path` → 3 层 Split-Path 到 Git root → `bin\bash.exe`。git 几乎总在 PATH(Git for Windows 必装)。exec-path 通常如 `C:\Program Files\Git\mingw64\libexec\git-core`,3 层 up 到 `C:\Program Files\Git`。try/catch 包裹(git 不可用时安全降级)。
