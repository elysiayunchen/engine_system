# CHANGE-2026-07-29-05 - v6.14.1 em-dash 编码 hotfix

> Created: 2026-07-29 · Status: verified · Related: T-056 · Supersedes: 无

## Goal

修复 Windows PowerShell 5.1 + zh-CN locale 下 .ps1 文件中 em-dash(`—`)导致的控制台输出乱码。实测 em-dash 渲染为 `鈥?`(UTF-8 字节 `E2 80 94` 被 GBK 解码为 `鈥` + 残字节 `?`)。本次扫描发现 7 个 .ps1 含非 ASCII,但只有 3 处出现在用户可见的 Write-Warn/Fail 字符串字面量,优先修复这 3 处。其余 `§` / here-string 中文模板问题留独立任务卡。

## Actual Changes

**A. 3 处 em-dash `—` → ASCII `-`(engine + plugin 镜像 + test)**

- A-1: `engine/scripts/engine-doctor.ps1` L1318 `check_engineignore` 的 Write-Warn 文案。
- A-2: `plugin/engine/scripts/engine-doctor.ps1` L1318 镜像(byte-identical)。
- A-3: `tests/workstream/test_engine_verify_env_cleanup.ps1` `Fail` 函数输出前缀 `FAIL  $name — $detail` → `FAIL  $name - $detail`。

**B. 验证**

- B-1: 实测 em-dash 渲染:`鈥?`(乱码)已消失。
- B-2: `tests/workstream/test_engine_verify_env_cleanup.ps1` 2/2 PASS(回归)。
- B-3: `bash scripts/check.sh` CHECK PASSED。

## Impact Scope

- `engine-doctor.ps1` L1318 Write-Warn 文案:乱码消失,语义不变。
- `test_engine_verify_env_cleanup.ps1` Fail 函数:仅影响 FAIL 路径输出(测试 PASS 路径不变)。
- 其他 .ps1 文件:不动。

## Risk & Watchpoints

- **风险**:em-dash 在英文 Windows(cp1252)locale 下也可能乱码(渲染为 `â€"`)。本次只修 zh-CN 实证场景,但 ASCII 化对其他 locale 也有效。
- **watchpoint**:其余 6 个 .ps1 文件仍含非 ASCII(注释/§/here-string 中文模板)。`§` 在 GBK 下解码为汉字 + 数字(轻度乱码,可读);here-string 中文模板会被写入 .md 文件(永久乱码)。留独立任务卡处理。
- **不引入 BOM**:BOM 方案会触发 62+ 文件 checksum 漂移,破坏 plugin 镜像 byte-identical 约束,本次不用。
