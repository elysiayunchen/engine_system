# CHANGE-2026-07-29-11 - T-063 v6.17.2 migrator bump prompt + doctor set -e fix

> Created: 2026-07-29 · Status: verified · Related plan: none

## Goal
Fix GitHub issue #15 (D-13): `engine update` via `engine-migrate-contract` implicitly bumps the contract-version stamp without prompting the user to review active/paused task cards that may reference the old version. Implement Option A (migrator bump detection + prompt in 4 mirrored files + 2 test files).

## Actual Changes
- **engine-migrate-contract.sh / .ps1 + plugin mirrors (4 files)**: Added `OLD_CONTRACT_VERSION` capture loop before upsert_block calls. Reads existing `<!-- contract-version: X -->` stamp from AGENTS.md / SYSTEM.md / ENGINE_DOCTOR.md. After upsert, if `OLD != NEW` and TOUCHED non-empty, prints "contract-version bumped: $OLD -> $NEW" + lists active/paused task cards (`engine/tasks/T-*.md` with `status: active|paused`).
- **Fresh-install crash fix (migrator L542)**: `grep -oE` returns 1 on no-match; with `set -euo pipefail` the assignment `_existing="$(...)"` failed and triggered `on_error` → exit 1. This crashed the migrator on fresh installs (no prior managed block), causing install.sh I6 test to FAIL (AGENTS.md never got the contract-version stamp). Fixed by appending `|| true` inside the `$(...)`, matching the existing `plan_section`/`sample_row` pattern at L345/L348.
- **Doctor latent set -e fix (engine-doctor.sh L1494 + plugin mirror)**: `check_multi_card_writeset_overlap` used `entries="$(grep '^WRITE-SET:' "$card" | ...)"`. When an active card uses the `## WRITE-SET` bullet-list format (T-061) instead of the `WRITE-SET:` single-line format, grep returns 1 (no match), pipefail triggers `set -e`, and the doctor exits 1 silently (no FAIL/WARN output, no summary line). Fixed by appending `|| true` after the assignment.
- **tests/update-flow/test_migrator_bump_prompt.sh / .ps1 (2 files)**: S1 bump+active card / S2 idempotent repair / S3 bump no active cards / S4 fresh install (no prior stamp) — regression test for the fresh-install crash.
- **plugin/manifest.json**: Updated sha256 for engine-migrate-contract.sh (58accc68...) and engine-doctor.sh (730d5460...) after the `|| true` fixes.

## Impact Scope
Engine runtime layer (migrator + doctor + tests + manifest). No contract source changes, no user project memory changes.

## Risk & Watchpoints

All current active cards have a WRITE-SET section, so this is a latent edge case deferred to a future task.
