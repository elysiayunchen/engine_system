# CHANGE-2026-08-01-02 — Engine Doctor 跨 shell 健康收口

## Goal

消除仓库级 Engine Doctor 的硬失败，并修复 Windows/WSL 下 Bash 生命周期验证的跨 shell 路径与证据排序不一致问题。
