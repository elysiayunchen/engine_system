# CHANGE-2026-08-01-02 — Engine Doctor 跨 shell 健康收口

## Goal

消除仓库级 Engine Doctor 的硬失败，并修复 Windows/WSL 下 Bash 生命周期验证的跨 shell 路径与证据排序不一致问题。

## Actual Changes

- 为 root/plugin Doctor 增加 Windows Python 接收 MSYS POSIX 路径时的 JSON 校验兼容。

- 让 verify 在后续 AC 前刷新前序 AC 产生的 MANIFEST，并让 close 在 Gate 与 CLOSE 写入后刷新最终 MANIFEST，消除正常生命周期中的瞬时自篡改。

- 补齐 T-081 的 verify、review、agent-review、prove、gate、close 证据及跨 shell 回归测试。
- 保留历史 evidence、旧任务卡、tag/VERSION 和孤儿 workstream 等可解释 warning，不把它们降格为静默通过。
