# D-003 — S3 契约编译：src → dist + 幂等校验 + 减法规则
> status: approved
> date: 2026-07-03
> expiry: none
> scope: contract/**, ENGINE_FILE_SYSTEM_v5.md, scripts/check.sh, scripts/check.ps1, tests/**, engine/ENGINE_MAP.md, engine/CONTEXT.md, engine/HANDOFF.md, engine/decisions/**, engine/tasks/**

选项: A 建立编译机制 + 减法规则(选定) / B 全量细分源模块 / C 不做编译,只手动减法
理由: S2 已落地分形记忆;S3 拆棘轮的核心是让契约从「agent 背诵」变成「机器编译产物」。本切片建立机制(contract/src → compile → dist + 幂等校验 + 减法规则基线),低风险可独立发布;源模块细分留 S3-b。减法规则用行数基线强制「新增须净零增长」,从根因打断复杂度棘轮。
后果: 引入 contract/src/(契约源)、contract/compile.{sh,ps1}(编译器)、contract/budget.json(减法基线);dist 加编译横幅(头注);check 加编译幂等 + 预算校验;契约头标「由编译产出,勿手改 dist」。compile 脚本是引擎仓库工具,不分发(契约是引擎产品本身,非用户项目内容)。
