# D-006 — v6 体系完善批次2a：pre-commit 认 done 任务卡 + 安装
> status: approved
> date: 2026-07-03
> expiry: none
> scope: engine/scripts/githooks/pre-commit, plugin/engine/scripts/githooks/pre-commit, tests/**, engine/ENGINE_MAP.md, engine/CONTEXT.md, engine/HANDOFF.md, engine/decisions/**, engine/tasks/**

选项: A 修 fallback + 安装(选定) / B 只修不装 / C 只装不修
理由: .git/hooks/pre-commit 未装(D6 缺口),B 层门禁形同虚设;且 pre-commit 只认 active 任务卡,done 后提交被拦(设计缺陷——任务完成后标 done 再提交是正常流程)。修 fallback(无 active 时用最新 done 任务卡的 decision,scope 仍校验)+ 安装到 .git/hooks/,让 B 层门禁真正生效且不破坏提交流程。
后果: pre-commit 加 fallback 逻辑;本仓库 .git/hooks/pre-commit 安装;tests/task-card 加 done fallback 场景。门禁 B 层从「形同虚设」变「真正生效」。pre-commit 是 POSIX sh(B 层跨平台用 git 自带 sh),无 ps1 孪生。
