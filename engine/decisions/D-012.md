# D-012 — 门禁严格度：WRITE-SET 越界 = block（非首次警告）
> status: approved
> date: 2026-07-03
> expiry: none
> scope: engine/scripts/engine-hook-stop.*, plugin/engine/scripts/engine-hook-stop.*

选项: A WRITE-SET 越界 block(选定) / B 首次警告 / C 警告+记录
理由: 设计文档 §9.3 推荐「写集越界首次警告」,但 §5.2 规定「越界=机器拦截」。实现选择 block(与 §5.2 一致),因为 WRITE-SET 是任务卡声明的授权范围,越界即未授权,应硬拦;FORBIDDEN 是架构师否决权,必拦。capsule 缺失用 warn(给存量缓冲,§9.5)。本决策补记录 §9.3 未决的选择。
后果: Stop hook 对 WRITE-SET/FORBIDDEN 越界 decision:block;capsule 缺失 systemMessage warn。无代码改动(实现已是 block),本决策补记录。
