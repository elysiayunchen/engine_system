# D-020: Budget Baseline Increase for Developer Communication Rule v6.2

| Field | Value |
|-------|-------|
| status | approved |
| scope | contract/budget.json, contract/src/00-core.md |
| expiry | never |

## Context
The Developer Communication Rule was expanded from v6.1 (5 static points) to v6.2 (6 dynamic points + feedback signals + comm_level adaptation + multi-agent applicability). This added ~14 lines to contract/src/00-core.md, requiring a budget baseline increase from 2441 to 2455 and max_rules from 12 to 13.

## Options Considered
1. **Increase baseline to 2455/13** — accommodates the full v6.2 expansion (chosen)
2. **Trim other contract content to offset** — rejected: v6.2 content is architect-approved and should not be compressed
3. **Split rule across multiple files** — rejected: rule coherence requires single-file placement

## Decision
Increase `contract/budget.json` baseline to max_lines: 2455, max_rules: 13. The Developer Communication Rule v6.2 is essential for multi-agent support and developer accessibility.

## Consequences
- Budget headroom consumed: +14 lines, +1 rule
- Future additions must net-zero against 2455 baseline
- Contract debt baseline stays at 46 (one MUST was added by comm_level, increasing actual debt to 47 — monitor and reduce elsewhere)
