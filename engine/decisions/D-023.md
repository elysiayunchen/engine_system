# D-023: Installer pre-commit hook 智能覆盖

| Field | Value |
|-------|-------|
| status | approved |
| scope | install.ps1, install.sh |
| expiry | never |
| decided | 2026-07-14 |

## Context

Installer 的 keep-existing 逻辑导致 .git/hooks/pre-commit 永远不更新。`engine update` 拉了新源文件(engine/scripts/githooks/pre-commit),但 .git/hooks/pre-commit 因已存在而保留旧版。诺识项目的 hook 卡在 32 行旧版(只查 CONTEXT/HANDOFF 同步),源文件已是 136 行新版(两层门禁)。

## Decision

将 keep-existing 逻辑改为智能覆盖:
1. 检查现有 hook 是否含 `Engine System.*pre-commit hook` 标记(引擎管理)
2. 引擎管理 → 比较内容(SHA256/diff),不同则覆盖,相同则报 "up to date"
3. 用户自定义 → 保留,提示手动 merge(现有逻辑不变)

## Rejected alternatives

- **总是覆盖**:不安全,会覆盖用户自定义 hook(husky/pre-commit framework 等)
- **提示用户手动 merge**:用户不会做,导致 hook 永远不更新(当前问题的根因)
