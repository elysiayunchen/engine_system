# D-026: v6.5.0 发布与 CI 加固

> approved: 2026-07-17 用户明确要求提交、发布升级并确保远端可更新拉取；该授权包含修复发布过程中暴露的 CI/Release 阻塞。

## Decision

1. v6.5.0 tag 只在 main CI 全绿、远端 VERSION/install 内容核对通过后推送。
2. CI 和 Release 必须调用正式 `install.sh --local plugin`，不得通过 sed 绑定下载函数实现细节。
3. source/plugin 镜像在 Windows checkout 后仍须字节一致；用 `.gitattributes` 固定对应孪生文件行尾。
4. GitHub Actions 日志不可读时，检查器/关键步骤输出公开 `::error` annotation 以提供根因，不以 `--no-verify` 绕过。
5. plugin manifest 覆盖的是文本内容完整性，SHA256 统一按 LF 规范化计算与验证；release 压缩包 checksums 仍按原始归档字节计算。
6. 项目内 `engine/bin/engine` 与发行 `plugin/bin/engine` 保持 Git executable bit，installer 同时显式 chmod，保证 Unix 项目可直接执行 CLI。

## Consequences

- 发布可能多一次修复提交与 CI 重跑，但 tag 不指向已知失败提交。
- 发布完成后 T-030 evidence、CONTEXT/HANDOFF 和 capsule 记录远端 SHA、CI/Release 结果与回滚边界。
