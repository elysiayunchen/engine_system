## Decision

1. **批准 T-037 元准则任务**:把"Trae 相关开发 agent 工具(TRAE IDE / TRAE Work / TRAE CLI / TRAE Plugin)下 NEVER 主动中止对话,用 AskUserQuestion 延续"作为开发准则加到 `engine/SYSTEM.md`「项目开发准则」段,与 `user_profile.md` 的 Trae agent tool continuity 准则双轨(机器自动注入 + 项目级 system 显式声明)。

2. **本卡不承载机制设计**:T-037 是元准则任务(改 SYSTEM.md 加 11 行子段),无机制设计争议,不需要 4 路子代理审视。本卡仅作为 protected_paths 的背书——pre-commit hook 要求 staged 中的 engine/tasks/T-037.md 必须有 approved decision 覆盖。

3. **副作用:T-036 → paused**:T-037 执行时需要让 T-037 成为唯一 active 任务(PreToolUse 在 contract-version 6.5+ 项目中要求 active task 存在),所以 T-036 → paused(已 staged 同步)。T-037 完成后 T-036 恢复 active。

4. **scope 覆盖 T-037 WRITE-SET 全集 + T-036.md/spec.md 同步 paused + D-031 自身**:本卡 scope 必须覆盖所有 staged 文件,包括:
   - T-037 WRITE-SET 全集(engine/SYSTEM.md, engine/tasks/T-037.{md,spec.md}, engine/CONTEXT.md, engine/HANDOFF.md, engine/changes/CHANGE-2026-07-20-03.md, engine/evidence/T-037/**)
   - T-036.md + T-036.spec.md(paused 状态同步,是 T-037 执行前置)
   - D-031.md 自身(在 protected_paths 内,需自引用)

## Consequences

- **positive**:T-037 元准则任务可通过 pre-commit hook 落地。所有未来 agent 会话(本仓 + 安装到外部项目的 agent)默认遵守 Trae continuity 准则。
- **negative**:无机制设计风险。准则依赖 agent 自觉遵守,无 hook 检测——若未来需要机器强制(如 hook 检测对话末尾是否有 AskUserQuestion 调用),需另开决策卡。
- **neutral**:本卡是 protected_paths 背书卡,不是设计决策卡。撤销 T-037 准则只需 Edit engine/SYSTEM.md 删除子段,不需要覆盖本卡。
