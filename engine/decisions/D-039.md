# D-039: Quality Gate Enforcement — 契约基线提升 + done 过渡门禁条款

status: approved
scope: contract/src/00-core.md, contract/budget.json
date: 2026-08-01
decided-by: architect

## Context

v6.24.0 Gatekeeper 子系统将质量门禁（verify/review/review-agent/prove）从 Doctor 建议性升级为 pre-commit 硬拦截。需要在契约中增加对应条款，使门禁执行成为契约级义务而非仅脚本行为。

## Decision

1. 在 Behavior Verification Rule (v6 S4) 末尾追加 Quality Gate Enforcement 扩展段（~6 行），描述 GATE.json 聚合 + done 过渡硬拦截 + --no-verify 封死。
2. 契约行数基线从 2940 提升至 2980（+40 行余量），容纳门禁条款 + 后续 v6.24.x 补丁。
3. 规则数不变（13 条），门禁条款作为 S4 扩展而非独立规则。

## Rationale

- 门禁执行是"completion has evidence"（N3）的自然延伸：从"AC 有证据"扩展到"所有质量维度有证据"。
- 不新增规则避免 max_rules 提升（13 已满载）。
- 基线提升 40 行而非精确 6 行，为 v6.24.x 迭代留余量（每次 recompile 可能微调行数）。

## Expiry

永久（结构性决策）。
