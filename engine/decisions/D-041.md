# D-041: Review from Receipt — 转换命令方案

status: approved
scope: engine/scripts/engine-review-from-receipt.sh, engine/bin/engine, engine-doctor.sh, pre-commit
date: 2026-08-01
decided-by: architect

## Context

Issue #29: D-009 任务的独立 Reviewer 在 workstream 分片产出审查收据，但 doctor/pre-commit 只认 `engine/review/evidence/T-NNN/REVIEW.json`（writer=engine-review）。需要一条从 receipt 到 canonical evidence 的路径。

## Decision

采用**转换命令**方案（`engine review T-NNN --from-receipt <agent-id>`），而非门禁直接接受 receipt。

1. 新增 `engine-review-from-receipt.sh`（+ps1 mirror）：读 workstream receipt → 校验 status=pass → 绑定当前 HEAD → 写 canonical REVIEW.json。
2. Writer 标识为 `engine-review-from-receipt`，argv 记录完整命令含 `--from-receipt <agent>`。
3. Doctor writer 白名单扩展为 `engine-review|engine-review-from-receipt`（WARN 级，非 FAIL）。
4. Pre-commit writer 白名单同步扩展（硬拦截级）。
5. Receipt 格式：`engine/workstreams/T-NNN/agents/<agent-id>/REVIEW-RECEIPT.json`，最小字段 status/task/reviewer/summary。

## Rationale

- 成本不对称：转换命令只加一个 CLI 入口 + 两处白名单微调；门禁直接接受需 doctor/pre-commit/prove 三处加第三格式分支。
- Provenance 绑定：转换时自然写入 HEAD commit，复用全部已有 stale 守卫（D-040 ancestor-of-HEAD）。
- 先例同构：`engine review` 本身就是"把审查活动转成 REVIEW.json"；`--from-receipt` 只是输入源从 semgrep/eslint 换成文件。
- 单一 canonical 格式不变：所有下游消费方（prove/gate/close）零改动。

## Expiry

永久（结构性决策）。
