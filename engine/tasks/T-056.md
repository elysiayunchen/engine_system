GOAL: 修复 Windows PowerShell 5.1 + zh-CN locale 下 .ps1 文件中 em-dash(`—`)控制台输出乱码问题。根因:engine/scripts/*.ps1 文件保存为 UTF-8 无 BOM;PS 5.1 默认按系统 codepage(中文 Windows = GBK/CP936)读取无 BOM 的 .ps1 源文件;UTF-8 em-dash 字节 `E2 80 94` 被 GBK 解码为 `鈥`(E2 80) + 残字节 `?`(94 单字节无 trail) → 用户看到 `鈥?`。本次扫描发现 7 个 .ps1 含非 ASCII,但只有 3 处出现在用户可见的 `Write-Warn`/`Fail` 字符串字面量,优先修复这 3 处。其余 `§` / here-string 中文模板问题留独立任务卡。
