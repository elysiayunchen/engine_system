GOAL: 修复 CI/Doctor 报出的 3 个问题:(1) Windows Git Bash 下 `awk` 按字节计数导致 HANDOFF.md 长行误报(T-063 回归,2279 bytes > 2000 但 1978 chars < 2000);(2) `engine/checks/check-version-consistency.sh` git 文件模式 100644 应为 100755(Linux CI WARN);(3) skeleton ENGINE_MAP.md 是空模板,install 后 doctor 报 6 FAIL(核心文件未注册)。

## 问题清单

### P1 — HANDOFF.md 长行误报(Windows Git Bash only)
- 根因:`engine-doctor.sh:411` 用 `awk '{ if (length > max) max = length } END { print max+0 }'` 计数。Windows Git Bash 默认 C/POSIX locale,`awk length()` 返回**字节**数而非字符数。HANDOFF.md line 20 含大量中文(3 bytes/char in UTF-8),1978 chars = 2279 bytes。
- 现状:Linux 和 PowerShell doctor 不受影响(正确按字符计数)。仅 Windows Git Bash doctor 误报。
- 修复:用 `perl -CSD` 按 UTF-8 字符计数,awk 作 fallback(perl 不可用时)。

### P2 — check-version-consistency.sh 不可执行(Linux CI)
- 根因:`engine/checks/check-version-consistency.sh` git 文件模式 `100644`,Linux 上无执行权限。doctor `run_custom_checks` 的 `[ ! -x "$script" ]` 检查触发 WARN。
- 修复:`git update-index --chmod=+x`。

### P3 — Install dry-run 6 doctor FAIL(skeleton ENGINE_MAP.md 空模板)
- 根因:`plugin/engine/skeleton/ENGINE_MAP.md` 是空模板("空模板。引擎已安装但尚未初始化"),§1 无任何注册条目。install + migrator 后磁盘有 SYSTEM.md/CONTEXT.md/GLOSSARY.md/HANDOFF.md/ENGINE_MAP.md/ENGINE_DOCTOR.md,但均未注册 → doctor `check_disk_to_registry` 对 6 个文件报 FAIL。
- 现状:CI 测试脚本降级为 WARN 所以 CI 仍绿,但 doctor 输出有 6 FAIL + 4 WARN。
- 修复:skeleton ENGINE_MAP.md 预注册 6 个核心文件 + §0 profile 占位。
