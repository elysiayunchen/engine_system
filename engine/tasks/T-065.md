GOAL: 修 issue #21 — pre-commit hook L234-238 的 closing_paths 收集逻辑把所有 staged + status:done 的任务卡当作 "closing" 加入 governing_files,不区分「新 close(active→done)」与「修改已 done 卡(HEAD 已 done,本次只改内容)」。导致修改已 done 卡时该卡被误加入 governing,其 WRITE-SET 不覆盖的文件被 union check 拦截,只能 --no-verify 绕过。修复:在检查 staged 卡 status:done 后,额外检查 HEAD 是否已 done;HEAD 已 done 则不是 closing,跳过(与 issue #18 的 AC PASS 检查修复模式一致,L375-381)。
