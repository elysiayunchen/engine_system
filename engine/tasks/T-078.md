## CONSTRAINTS

- `blocked` is machine-recognized evidence, never a passing status and never an exit-0 result.
- The frozen verify command always runs first; behavior diagnostics are supplementary and cannot overwrite its exit result.
- Auto coverage diagnosis is conservative: only coverage threshold signatures trigger a `--no-cov` pytest diagnostic.
- Do not add a Python runtime dependency to engine-verify; JSON remains shell/PowerShell generated.
- `engine/scripts/engine-verify.{sh,ps1}` and plugin mirrors remain behaviorally aligned; plugin shell/PowerShell copies are byte-identical to engine copies.
