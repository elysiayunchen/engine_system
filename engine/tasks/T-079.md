## CONSTRAINTS

- D-019: file-layer orchestration only; no LLM/API/process-manager integration.
- Keep the existing gate config semantics; `engine close` is the lifecycle coordinator, not a new quality policy.
- Worker sessions may write only their own `engine/workstreams/<task>/sessions|agents/` shard; shared CONTEXT/HANDOFF remain coordinator-owned.
- Bash and PowerShell must fail closed on missing task/scripts and preserve non-zero child exit codes.
- Evidence provenance must distinguish a real `engine ...` CLI invocation from direct script execution; do not retain a hard-coded false argv.
- Workstream memory paths emitted by `engine workstream` and accepted by pre-commit must remain compatible for both legacy two-level and canonical sessions/agents layouts.
