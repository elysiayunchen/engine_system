## ISSUES (boundary bugs)

- **B1** injection budget 估算硬编码(40/50/80)——runtime-law/CONTEXT 超限行时估算偏低,budget guard 失效
- **B2** gate filesystem fallback 的 glob.glob 在 Windows 正斜杠 WRITE-SET 路径可能匹配不到
- **B3** drift detection GOAL 关键词提取依赖 `^GOAL:` 行首,非标准写法静默失败
- **B4** PS1 session-start $activeCount 在 tasks 目录不存在时未初始化
- **B5** capsule heat doctor check 对缺失 META 字段无 graceful fallback
- **B6** doctor 全量遍历性能(>10min)——需增量模式或状态缓存

## ISSUES (open-source internalization)

- **O1** shellcheck 模式内化：引擎自检脚本 lint（非外部依赖，提取规则子集为 doctor check）
- **O2** BATS 测试模式内化：TAP 输出 + setup/teardown 骨架（替换手写 assert helper）
- **O3** jq JSON 操作模式内化：纯 bash JSON 解析函数库（减少 Python subprocess 依赖）
- **O4** conventional-changelog 模式内化：commit message → CHANGE 胶囊自动生成
- **O5** cursor-rules 跨宿主格式适配：D-042 实施参考
- **O6** tiktoken 精确计数内化：injection budget 从行数估算升级为 token 估算
