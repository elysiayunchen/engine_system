# engine-system

**Persistent AI memory for vibe coding projects.**  
Drop this into any project. Claude remembers everything across sessions.

---

## What it does

Every AI session starts fresh — no memory of your project, your rules, or what you did last time.  
Engine System fixes that by giving your project a structured memory layer that Claude reads automatically.

After a 10-minute interview, you get 8 markdown files in `engine/`:

| File              | Purpose                                     |
| ----------------- | ------------------------------------------- |
| `ARCHITECTURE.md` | Tech stack, directory structure, data model |
| `CONTEXT.md`      | Current state, what's broken, blockers      |
| `SPRINT.md`       | Active tasks and priorities                 |
| `ROADMAP.md`      | Milestones and planned features             |
| `PITFALLS.md`     | Known bugs, footguns, never-do list         |
| `SYSTEM.md`       | Collaboration rules and AI directives       |
| `HANDOFF.md`      | Session history and recovery points         |
| `SOURCEMAP.md`    | Code map and feature-to-file index          |

Claude Code loads these automatically. No more re-explaining your project every session.

## Install

**macOS / Linux:**

```bash
bash <(curl -sSL https://raw.githubusercontent.com/elysiayunchen/engine-system/main/install.sh)
```

**Windows (PowerShell):**

```powershell
irm https://raw.githubusercontent.com/elysiayunchen/engine-system/main/install.ps1 | iex
```

**Via degit (no git history):**

```bash
npx degit elysiayunchen/engine-system/plugin
```

Adds these files to your project — nothing else is touched:

```
your-project/
├── engine/              ← engine files live here (generated by /engine-init)
├── .claude/
│   └── commands/        ← Claude Code slash commands
│       ├── engine-init.md
│       ├── engine-update.md
│       ├── add-pitfall.md
│       └── engine-status.md
└── CLAUDE.md            ← auto-loaded by Claude Code
```

---

## Usage

### First time setup

Open Claude Code in your project and type:

```
/engine-init
```

Claude will interview you about your project (~10 min) and write all engine files directly to `engine/`.

> **Web Claude fallback:** Copy `.claude/commands/engine-init.md` and paste it into claude.ai. Save the generated files manually to `engine/`.

### Every session after that

Claude Code reads `CLAUDE.md` automatically — no action needed. Just start working.

End of session:

```
/engine-update
```

Syncs current state and writes a handoff note.

### Other commands

```
/add-pitfall    — record a bug or footgun right now, before you forget
/engine-status  — print current project snapshot
```

## Update the plugin

To get the latest command files without overwriting your engine data:

```bash
bash <(curl -sSL .../install.sh) --update
# or
.\install.ps1 -Update
```

Your `engine/*.md` files are never touched by updates.

---

## How it works with Claude Code

`CLAUDE.md` is automatically loaded by Claude Code at session start. It instructs Claude to read `engine/*.md` before doing anything, and registers the slash commands.

Engine files are plain markdown — version control them like any other project file. They're the source of truth for your project's AI memory.
